### Projects

**[AXI4 Interconnect: RTL, UVM Verification & Zynq Bring-Up](https://github.com/eitanmarock/axi4-interconnect-uvm)**
A custom 2-master × 3-slave AXI4 interconnect written in SystemVerilog, verified with UVM and SVA, packaged as IP, and brought up on a PYNQ-Z2 (Zynq-7020) running bare-metal C. The repo includes a write-up of four hardware bring-up bugs and how they were found.

**[ESP32 TinyML Predictive Maintenance](https://github.com/eitanmarock/esp32-tinyml-predictive-maintenance)**
Real-time DC motor fault detection on an ESP32-S3: a dual-core FreeRTOS design, a from-scratch FFT, and an Edge Impulse classifier that cuts motor power through a MOSFET when it detects a fault.

**[Electronic Safe: Discrete Digital Logic](https://github.com/eitanmarock/electronic-safe-digital-logic)**
A combination lock built with no microcontroller, using flip-flops, counters, monostables, a 555 timer and 7-segment decoders. Designed in NI Multisim and built on a breadboard.
